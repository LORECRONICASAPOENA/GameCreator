3 · Exporte para outro jogo

O catálogo mantém os IDs, as propriedades dos itens, os efeitos declarados e as receitas do projeto original. Para ficar leve, o JSON de runtime não repete os dados base64 das imagens. Os ícones precisam ser exportados ou copiados como arquivos PNG separadamente.

No Godot 4, o script integracao/godot/ApoenaCatalogo.gd consegue carregar esse catálogo e executar o fluxo inicial de coletar e fabricar. Instale-o em uma cópia do jogo primeiro. Os efeitos de combate, imagens e animações dependem de conexão às cenas reais.

4 · Teste de vínculo entre ingredientes e produtos

Este teste é isolado: monta os ingredientes no inventário de uma simulação local e verifica se a receita produz o item correto. Não altera os salvamentos dos jogos.
