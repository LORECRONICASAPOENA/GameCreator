# Apoena Game Creator V4.1 — Estúdio unificado

**Abra index.html** para usar o único menu do Creator no Android ou PC. O mesmo menu contém Creator 3D V4.0, Pixel Art, Personagens, Animais, Cenário/Plantas, Efeitos, Editor de Mapas 2.5D e Itens/Receitas.

A V4.0 original foi preservada em APOENA_GAME_CREATOR_V4_0_BANCADA_INTEGRADA.html; o iniciador antigo em legacy/iniciador-anterior.html. Não misturar arquivos do editor com o jogo Apoena Agar.

No menu Pixel Art, importe PNG/WebP/JPG, marque grade ou corte manual, apague sobras, remova fundo por cor conectada, visualize transparência e exporte spritesheet PNG/JSON para HTML/Godot. As imagens originais (Apoena, javali, abelha, colmeia) acompanham o pacote local de distribuição, mas ainda não foram incorporadas como binários a esta branch.

Veja ORGANIZACAO_EDITOR.md para detalhes e testes. A integração do sprite no jogo deve ser testada separadamente.
