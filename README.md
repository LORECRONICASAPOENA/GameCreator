# Apoena Game Creator

Repositório exclusivo do **Apoena Game Creator**, editor visual offline de jogos em HTML/CSS/JavaScript, com exportação de referência para Godot 4.

## Importação inicial

O projeto completo (v3.9, Fábrica de Itens, Editor de Layout, 52 poções, recursos e módulos) foi preparado em um pacote de migração. **Este README apenas inicializa o repositório.** Os arquivos do programa serão enviados executando `PUBLICAR_NO_GITHUB.cmd` do pacote no Windows, usando Git.

Depois da publicação:
- `APOENA_GAME_CREATOR_OFFLINE_v3_9_EDITOR_VISUAL.html` — aplicativo offline completo.
- `FONTES_V3_9/` e `MODULOS/` — módulos e fontes.
- `FONTES_52_POCOES/` e `INTEGRACAO_GODOT_REFERENCIA/` — dados e integração.
- `HISTORICO/` e `BACKUP_ORIGINAL_v3_8.zip` — histórico e backup.

**Projetos separados:** não enviar conteúdo do jogo `JOGO-APOENA-AGAR-`, do `Apoena Studio Maker` nem da `LORE-ENGINE-1.0.0` para este repositório.

**Visibilidade:** o repositório é público; não publicar tokens, senhas ou dados privados.
