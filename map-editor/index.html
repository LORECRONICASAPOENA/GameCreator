1 · Pincel e terreno

Caminhos unem-se automaticamente no editor. O atlas importado também pode ser pintado peça a peça.

2 · Importar sua folha de terreno

Para tiles de 32 × 32, selecione um quadradinho da folha abaixo; ele vira seu pincel. Aceita PNG de 128 × 128, 256 × 256 e maiores.

Nenhuma folha importada.

3 · Objetos 2.5D

PNG com transparência recomendado. Selecione um objeto e toque no mapa para colocá-lo. Use Apagar para removê-lo.

Prévia do mapa editável
Toque e arraste para pintar. Selecione Mover câmera para percorrer o mapa. No computador, use a roda do mouse para ampliar. Caminhos e grama são provisórios até importar a arte final.
Mapa de teste carregado. Selecione Caminho automático e arraste para desenhar rotas como no RPG Maker.

4 · Estrutura MOBA

Marcadores são posições de projeto, não torres com combate implementado.

Visão geral

Dados do projeto

O JSON guarda tiles, objetos, atlas e marcadores. Pode ser importado de volta neste editor. A conexão dele com TileMapLayer no Godot e com a partida HTML ainda é a próxima integração.

Como usar sem perder nada

1. Importe seus PNGs de chão. 2. Pinte o terreno. 3. Adicione árvores, rochas e montanhas. 4. Clique em Salvar projeto JSON. 5. Abra depois usando Abrir projeto. 6. Exporte PNG para avaliar o visual.

O navegador tenta guardar um rascunho local, mas não substitui o download do projeto. Seus arquivos ficam no dispositivo; não são enviados para um servidor.
