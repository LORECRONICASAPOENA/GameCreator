Apoena Game Creator 4.1

O editor 3D e o editor Pixel Art estão no mesmo programa. Use index.html como entrada única.

Ferramenta Pixel Art

  1. Selecione Personagens, Animais, Cenário ou Efeitos.
  2. Importe imagem PNG/WebP/JPG, marque a grade ou recorte manualmente.
  3. Antes de exportar, apague sobras de outros quadros, limpe fundo e confira transparência.
  4. Exporte PNG com células padronizadas e manifesto JSON com direção/ação.

Preservação do projeto

A bancada 3D original, o gerador modular de personagens, o editor de mapas e os sistemas de itens/receitas permanecem nos mesmos arquivos. O antigo iniciador foi copiado para legacy/iniciador-anterior.html.

Arquivos

pixel-art/index.html é o gerador modular; pixel-art/estudio.html é o editor para imagens importadas; map-editor/index.html é o editor de mapas; integracao/index.html cuida de itens/receitas.

As imagens já criadas estão catalogadas no arquivo pixel-art/catalogo_assets_agar.json. Ainda precisam ser importadas para o GitHub; o pacote ZIP local é a biblioteca com as imagens originais disponíveis.

Não confundir exportação com jogo pronto: após recortar os sprites será necessário ligar as animações ao personagem no HTML e no Godot e validar cada transição.
